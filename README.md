# AnatomyVerse 3D/4D

Interactive living-anatomy learning app for medical students — **pilot test build**.

▶ Open the app: https://officercon9-stack.github.io/anatomyverse/

Educational use only. The 3D model is an original schematic (not anatomically accurate) and content is pending expert review.
This repository contains only the compiled app files.

## Third-party 3D content
`models/z-anatomy-heart.glb` is derived from **Z-Anatomy — The libre 3D atlas of anatomy** (CC BY-SA 4.0), itself derived from **BodyParts3D, The Database Center for Life Science** (CC BY-SA 2.1 Japan). Converted and optimised for AnatomyVerse; this derived model is shared under **CC BY-SA 4.0**.
`data/ta2.json` is from the Z-Anatomy TA2 terminology list (CC BY-SA 4.0).
